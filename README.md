## 📋 О моде

**RP-MXTR-RPGA** — ролевой мод, превращающий ванильный Minecraft в полноценную
RP-игру: фракции с рангами и формой, живые NPC с работой и диалогами, 3D-транспорт
на реальных OBJ-моделях, оружие с патронами и гильзами, тюрьма с замками,
пожарная система, жажда и температура, документы, собственные звуки
и встроенные баг-репорты прямо из игры.

## 🚀 Установка

### 1️⃣ Одиночная игра / локальный сервер

| Шаг | Действие |
|:--|:--|
| 1 | Скачай нужную версию из [таблицы версий](#-версии) |
| 2 | Установи **Fabric Loader ≥ 0.16.9** для Minecraft 1.21.10 |
| 3 | Установи **Fabric API 0.138.4+1.21.10** |
| 4 | Кинь `.jar` мода в папку `mods/` |
| 5 | Готово ✅ |

```
.minecraft/
├── mods/
│   ├── fabric-api-0.138.4+1.21.10.jar   ← обязательно
│   └── RP-MXTR-RPGA-v56.1.0_alfa.jar   ← мод
└── config/
    └── rpga-mxtr-rpga/                     ← создастся автоматически
```

### 2️⃣ Выделенный сервер

> ⚠️ Мод **client + server** — на клиенте и на сервере должна стоять
> **одна и та же версия**.

> 🌐 **Актуальная серверная сборка — [56.1.0-alfa](versions/56.1.0-alfa/).**
> Беты **51.3 / 51.4** — устаревшие черновики, их ставить нигде не нужно:
> всё, что в них было, уже есть в 56.1.0-alfa. Подробнее в разделе
> [Версии](#-версии).

### 3️⃣ Зависимости

| Зависимость | Версия | Обязательна |
|---|---|:---:|
| Fabric Loader | ≥ 0.16.9 | ✅ |
| Fabric API | 0.138.4+1.21.10 | ✅ |
| Java | 21 | ✅ |
| Not Enough Animations | вшит в мод | ➖ |

## ⌨️ Управление

| Клавиша | Действие |
|---|---|
| `R` | Перезарядка оружия |
| `H` | Сесть в машину / на блок |
