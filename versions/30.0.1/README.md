## 🆕 Что нового в 30.0.1

### 🌐 Приложение «Даркнет»

В смартфоне появилось **новое приложение — «Даркнет»**. Раньше смартфон
был просто предметом без наполнения, теперь у него появилось первое
полноценное приложение с интерфейсом.

| Что появилось | Назначение |
|---|---|
| 🌑 **Экран «Даркнет»** | Отдельное приложение-экран внутри смартфона |
| 🔄 **Синхронизация состояния** | Пакет `darknet_sync` — сервер передаёт клиенту актуальное состояние |

| Поле | Описание |
|---|---|
| 🎯 **Разыскивается** | Признак того, что персонаж в розыске |
| ⏱ **Таймер** | Обратный отсчёт состояния |
| 🔃 **Обновление** | Синхронизация изменений с сервером |

### 🧩 Технически

| Класс | Назначение |
|---|---|
| `DarknetScreen` | Экран приложения «Даркнет» (наследует базовый экран приложений смартфона) |
| `RPGAPayloads$DarknetSyncPayload` | Сетевой пакет синхронизации состояния даркнета |

Класс экрана наследуется от общего базового класса приложений телефона,
поэтому «Даркнет» открывается так же, как и остальные приложения смартфона,
а его состояние приходит с сервера отдельным пакетом.

## 📜 Историческая справка

> ⛔ **Эта версия больше не используется на сервере RPGA.**
> Изначально именно **30.0.1** была задеплоена на сервере RPGA, и именно
> тогда была зафиксирована её надёжность для спецопераций: состояние
> «Даркнета» приходило **с сервера**, а не считалось на клиенте.

| Факт | Пояснение |
|---|---|
| 🕐 **Период на сервере** | 12.09.2026 — 03.10.2026 |
| 🌐 **На чём заменили** | [56.1.0-alfa](../56.1.0-alfa/) — вся логика 30.0.1 сохранена |
| 🔐 **Серверный источник истины** | Состояние «Даркнета» приходило пакетом `darknet_sync`, клиент его только отображал |
| 🕵️ **Надёжность для спецслужб** | Признак «в розыске» и таймер нельзя было подделать на клиенте — они считались на сервере |
| 🧱 **Минимальный риск** | Сборка не содержала тяжёлых подсистем 30.0.2 (тюрьма, замки, дым) |

> 💡 Устанавливать 30.0.1 имеет смысл **только** ради исторического сравнения
> или если сервер ещё не обновился. Во всех остальных случаях —
> **[56.1.0-alfa](../56.1.0-alfa/)**.
