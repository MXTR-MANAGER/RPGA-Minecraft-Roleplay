## ✅ Крашей и вылетов нет

`RP-MXTR-RPGA-30.0.1.jar` **не выкидывает игрока из игры**. Есть две
неработающие функции и один визуальный баг во фракциях.

---

## 🐛 Баги этой версии

| Баг | Что происходит с игроком | Вылет? |
|---|---|:-:|
| 🔴 **Ранг «Смотрителя» показывает «Неизвестно»** | Фракция `warden` («Служба безопасности») **уже есть**, но её ранг не прописан в системе титулов. Игрок видит вместо нормального ранга надпись **«Неизвестно»** — в чате, в форме, в списке игроков. Сама игра не падает | ❌ Нет |
| 🟡 **Заявка в друзья не отправляется** | Игрок жмёт «добавить в друзья» — заявка уходит не на ту сторону. Игрок видит пустоту, у другого игрока заявка не появляется | ❌ Нет |

### 🔍 Почему ломается «Смотритель»

| | |
|---|---|
| **Где** | `common/FactionRankSystem.java:26-53` |
| **Что** | В таблице титулов 7 ключей: `fso`, `fsb`, `dps`, `mchs`, `med`, `sk`, `army` |
| **Почему** | Ключа **`warden`** нет вообще |
| **Симптом** | `getRankTitle("warden", n)` возвращает заглушку `Неизвестно` для **всех** рангов 1–6 |
| **Статус** | ⛔ не исправлено ни в одной версии |
