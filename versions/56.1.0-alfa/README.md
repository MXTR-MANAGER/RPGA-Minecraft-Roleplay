### 🐛 Баг-репорты прямо из игры

**Новая функция**: отправка сообщений об ошибках в мод без копирования логов
вручную. Точки входа:

| Где | Как |
|---|---|
| ⏸ **Меню паузы** | кнопка **«Баг-репорт»** |
| 🏠 **Титульный экран** | отправка репорта прямо из главного меню |

| Поле | Значение |
|---|---|
| 📂 Категория | 7 вариантов: Геймплей · Краш · Графика · Сетевая · Звук · Глейч · Другое |
| 📝 Описание | до **2000 символов** |
| 🕶 Конфиденциальность | «Личная информация не будет раскрыта», «Заявление отправляется анонимно» |

**Как работает доставка:**

| Ситуация | Что происходит |
|---|---|
| 🟢 **В игре** (на сервере) | Репорт уходит на сервер **мгновенно** пакетом `BugReportPayload` |
| 🟡 **Вне игры** (титульный экран) | Репорт пишется в очередь `config/rpga-bug-queue/` и уходит, как только появится связь — обычно в течение ~10 секунд |
| 🔴 **Сервер недоступен** | Репорт остаётся в очереди и ждёт |

**Новые конфиги:**

| Файл | Где | Назначение |
|---|---|---|
| `rpga-bugreport.json` | клиент | endpoint, токен, таймаут (по умолчанию 5000 мс) |
| `rpga-bug-queue/` | клиент | очередь неотправленных репортов (`bug-*.json`) |
| `rpga-bugs.json` | сервер | база полученных репортов, максимум **500 записей** |

Серверная запись репорта: `id`, `createdAt`, `name`, `category`, `description`,
`modVersion`, `minecraftVersion`, `environment`, `player`.

> ⚠️ **Известный баг этой версии:** при отправке репорта **с титульного экрана**
> мод показывает «Связи нет — репорт сохранён и отправится позже», хотя репорт
> на самом деле **уходит на сервер** через ~10 секунд. Подробнее — в
> [KNOWN-ISSUES.md](../../docs/KNOWN-ISSUES.md#3-баг-репорт-говорит-не-успешно-но-уходит).

### 🔒 Замки v51.6 — теперь с сохранением

Замки переехали из «зоны 51.x» на сервер и получили **настоящее хранение на диск**.

| Что | Детали |
|---|---|
| 💾 **Файл конфига** | `config/rpga-locks.json` |
| 🧱 **Структура JSON** | `{ "locks": [ { pos, lock_id, owner, faction, mode } ] }` |
| 🧩 **Классы** | `common/RPGALockConfig.java` (загрузка + `createDefault`) |
| 🌐 **Сетевые пакеты** | 9 штук: `LockInfo` / `LockMode` / `LockOpen` / `LockMenu` / `LockRemove` / `LockHint` / `LockMenuInfo` / `LockInstall` |
| 🎨 **Интерфейс** | `LockActionsScreen` — меню действий с замком, `client/LockHintRenderer.java` — подсказка на HUD |

| Режим | Что умеет |
|---|---|
| 🔑 **Обычный** | Открывается ключом или отмычкой |
| 🪪 **По ключ-карте** | Требует определённую карту доступа |
| 🏛 **По фракции** | Открывается только представителям своей фракции |
| 🛡 **Pro** | Повышенная защита, несколько способов открытия |

### ⚠️ Баги этой версии — что осталось сломанным

⚠️ **В актуальной версии всё ещё есть 1 баг с вылетом клиента.**

| Баг | Что происходит с игроком | Вылет? |
|---|---|:-:|
| 🔴 **Перевод денег крашит игру** | Игрок открывает экран денег (кошелёк / банкомат) и жмёт **«Перевести»** или **«Снять»**. Пакет перевода **не зарегистрирован в системе пейлоадов** → игра падает с ошибкой, **клиент вылетает на рабочий стол**. Деньги **не списываются и не переводятся** — списание возможно только после ответа сервера, а ответа не было. Пока баг жив, **пользуйтесь переводом через ATM/банкомат на стороне сервера или избегайте экрана перевода**. | 💥 **ДА — краш клиента** |
| 🔴 Ранг «Смотрителя» показывает «Неизвестно» | Фракция `warden` («Служба безопасности») есть, но её ранг не прописан в `FactionRankSystem`. Игрок видит **«Неизвестно»** вместо ранга — в чате, в форме, в списке игроков. Всё остальное по фракции работает. | ❌ Нет |
| 🔴 Навигационные точки исчезают после рестарта | Точки навигации видны всем и работают, но список `navPoints` живёт **только в оперативной памяти сервера** и никуда не пишется. После перезапуска сервера **все точки пропадают**. | ❌ Нет |
| 🟡 Баг-репорт с титульного экрана врёт | Если отправить баг-репорт **до входа в сервер** (с титульного экрана), мод показывает «Нет связи — репорт не отправлен». На самом деле репорт **уходит**. С обратной стороны все проверки проходят, репорт приходит. Путает только игрока. | ❌ Нет |

> 🔍 Проверено по байткоду `RP-MXTR-RPGA-56.1.0-alfa.jar` и по исходникам текущей сборки.

Полное описание и способы обойти — в [KNOWN-ISSUES.md](../../docs/KNOWN-ISSUES.md).
