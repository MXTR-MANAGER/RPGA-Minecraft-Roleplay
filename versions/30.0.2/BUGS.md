## 💥 Баг, из-за которого нельзя играть

### 🔴 Перевод денег крашит игру

| | |
|---|---|
| **Где** | `item/RPGAMoneyItem.java:144-150` (объявление), `:197` (отправка) |
| **Что** | `MoneyTransferPayload`, id `rp-mxtr-rpga:money_transfer` — единственный пейлоад мода, объявленный не в `RPGAPayloads.java` |
| **Почему ломается** | Реализует `CustomPayload`, но **не зарегистрирован** в `PayloadTypeRegistry`. Остальные 126 пейлоадов зарегистрированы в `RPGACommonMod.java` — этот пропущен |
| **Что видит игрок** | Игрок открывает экран денег и жмёт **«Перевести»** или **«Снять»** → игра падает с ошибкой → **клиент вылетает на рабочий стол** |
| **Деньги** | **не списываются и не переводятся** — списание возможно только после ответа сервера, а ответа не было |
| **Кто страдает** | только отправляющий игрок. Сервер продолжает работать, остальные игроки не затрагиваются |
| **Технически** | `NullPointerException` при кодировании пакета: `CustomPayload$1.getCodec()` возвращает `null` для незарегистрированного id, и `PacketCodec.encode()` вызывается на `null` |
| **Статус** | ⛔ не исправлено ни в одной версии |

**Как избежать:** не переводить деньги через GUI. Управляйте балансами командой
`/rpga setbalance <игрок> <сумма>` — см. [ADMIN-GUIDE.md](../../docs/ADMIN-GUIDE.md).

## 🐛 Баги этой версии

| Баг | Что происходит с игроком | Вылет? |
|---|---|:-:|
| 🔴 **Ранг «Смотрителя» показывает «Неизвестно»** | Фракция `warden` есть, но её ранг не прописан в `FactionRankSystem`. Игрок видит **«Неизвестно»** вместо ранга — в чате, в форме, в списке игроков | ❌ Нет |
| 🔴 **Навигационные точки исчезают после рестарта** | Точки навигации видны всем и работают, но список живёт **только в оперативной памяти** (`RPGAServerMod.java:6252`). После перезапуска сервера **все точки пропадают** | ❌ Нет |
| 🟡 **Заявка в друзья не отправляется** | Игрок жмёт «добавить в друзья» — заявка уходит не на ту сторону. Игрок видит пустоту, у другого игрока заявка не появляется | ❌ Нет |

### 🔍 Почему пропадает навигация

| | |
|---|---|
| **Где** | `server/RPGAServerMod.java:6252` — `private static final List<NavPointEntry> navPoints = new ArrayList<>()` |
| **Почему** | Список живёт **только в оперативной памяти**. Файлового ввода-вывода нет **нигде** — ни в одном из 12+ JSON-файлов мода |
| **Симптом** | Игроки создают точки в Навигаторе телефона → после рестарта все точки пропали |
| **Статус** | ⛔ не исправлено ни в одной версии |

**Обходной путь:** точки приходится создавать заново после каждого рестарта.
Для постоянных точек используйте **блоки навигационных точек** (`navigation_point`)
— они хранятся в мире и не пропадают.
