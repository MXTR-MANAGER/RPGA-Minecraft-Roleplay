## 🐛 Баги этой версии

**Активных багов, которые ломают игру, в 1.0.0 нет.** Эта версия — первая
стабильная сборка, её можно ставить на сервер и играть без риска вылета.

| Баг | Что происходит с игроком | Вылет? |
|---|---|:-:|
| — | Критичных багов нет | — |
| 💡 Ранг «Смотрителя» (`warden`) | Не проявляется: фракции `warden` в этой версии **ещё не существует**. Она появится позже — тогда же появится и баг с рангом (см. [30.0.1](../30.0.1/)). | ❌ Нет |
| 💡 Перевод денег | Не проявляется: экрана перевода денег в 1.0.0 **ещё нет**. | ❌ Нет |
| 💡 Навигационные точки | Не проявляется: навигации в этой версии **ещё нет**. | ❌ Нет |

### 🏛 Фракции и униформы

| Элемент | Описание |
|---|---|
| **Спец-бочка фракции** | Блок-хранилище с конфигурируемым содержимым |
| **Иерархия рангов** | Система рангов с выдачей |
| **Приглашения** | Вступление во фракцию |
| **Выдача формы** | Раздача униформы фракции |

**Формы:** Военная, Полиция, ДПС, ФСБ, ФСО, Медицинская, MIL (куртка / штаны / каска / ботинки)

### 👥 NPC-система

| Элемент | Описание |
|---|---|
| **Сущность NPC** | 3D-модель NPC с иконкой на HUD |
| **Яйцо спавна NPC** | Предмет для создания NPC |
| **Админ-панель спавна** | Создание NPC через GUI |
| **Экран настроек NPC** | Конфигурация созданного NPC |
| **Панель взаимодействия** | Действия при клике по NPC |
| **Работа NPC** | Начать / закончить работу |

### 🚗 Транспорт

- 3D-машины на **реальных OBJ-моделях** с текстурным атласом
- Каталог машин, покупка, спавн
- Конфигурация списка машин

### 🧬 Выживание

| Система | Описание |
|---|---|
| **Жажда** | Отдельный HUD-индикатор |
| **Температура** | Влияние на игрока |
| **Голод** | Взаимодействие с едой |

**Еда и напитки:** бургер, картошка фри, жареное мясо, жареная рыба, жареное яйцо, суп, кола, сок, энергетик, бутылка молока

**Медицина:** аптечка, бинт, шприц, дефибриллятор

### 🗄 Документы и улики

Паспорт, водительское удостоверение, лицензия на оружие, блокнот, ручка, пакет с уликами, ключ-карта, отмычка, наручники, пластиковые хомуты

### 🛡 Снаряжение

Бронежилет, тактический жилет, баллистический щит, тактический шлем, тактические перчатки, противогаз, балаклава, фонарик, бинокль, рация Motorola, мегафон

### 🛠 Админ-панель

| Раздел | Возможности |
|---|---|
| Панель администратора | Главное меню |
| Выдача предметов | Любой предмет моды |
| Просмотр инвентаря | Инвентарь любого игрока |
| Деньги и баланс | Выдача и списание |
| Магазин | Торговля |
| Выдача рангов | Система рангов |
| Жалобы (репорты) | Приём, чат в репорте, назначение |
| Заморозка / фриз | Блокировка игрока |

### 💬 Чат

RP-чат с цветными никами, панель настроек чата

### 🚧 Прочие блоки и предметы

Барьер, дорожный конус, шипы на дороге, контрабанда, пачка денег, камера
