## 🐛 Нашёл баг?

На этой версии **нет встроенных баг-репортов** — они появились в `56.1.0-alfa`.

1. Открой [Issues](https://github.com/MXTR-MANAGER/RPGA-Minecraft-Roleplay/issues) → **New issue**
2. Укажи версию: **1.0.0**
3. Опиши: что делал → что ожидал → что получил
4. Приложи `logs/latest.log`
