## 🆕 Что нового в 12.1.0

### 📱 Смартфон

Новый предмет **`phone`** — полноценный игровой телефон с собственным интерфейсом
(экраны, приложения, взаимодействие). Это первое устройство такого рода в моде.

### 🔐 Авторизация через серверные команды

Добавлена серверная часть системы входа и авторизации — регистрация и вход
теперь обрабатываются на стороне сервера, а не только клиентом.

| Новый класс | Назначение |
|---|---|
| `CommandManagerAuthMixin` | Обработка команд авторизации |
| `CommandManagerServerCmdMixin` | Серверные команды мода |
| `ServerPlayNetworkHandlerAuthMixin` | Проверка авторизации при подключении игрока |

> 🔒 Без авторизации на сервере нельзя войти в систему — сервер проверяет
> учётные данные при подключении игрока.

### ➕ Добавленный предмет

| Предмет | Описание |
|---|---|
| 📱 **Смартфон** | Игровое устройство с интерфейсом и приложениями |
