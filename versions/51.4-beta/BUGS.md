# 🐛 Известные проблемы — RPGA 51.4-beta

💥 **Самая нестабильная версия из всех: 2 бага с вылетом клиента.**
Прочитай до установки — особенно если ты администратор сервера.

> [← README версии](README.md) · [Общий список по всем версиям](../../docs/KNOWN-ISSUES.md)

## 💥 Баг №1 — Настройки спавна мобов крашат админа

| | |
|---|---|
| **Где** | `RPGAPayloads.java:1188` (`MobSpawnCfgPayload`), `:1205` (`MobSpawnSyncPayload`) |
| **Где вызывается** | `AdminPanelScreen.java:180`, `MobSpawnSettingsScreen.java:56` |
| **Почему ломается** | Оба пакета реализуют `CustomPayload`, но **не зарегистрированы** в `PayloadTypeRegistry` → тот же NPE, что и в баге №2 |
| **Что видит админ** | Открывает **«Настройки спавна мобов»** (экран добавлен именно в этой версии) → игра падает → **клиент вылетает на рабочий стол**. Настройки применить невозможно — экран каждый раз убивает игру |
| **Кто страдает** | только администратор. Обычные игроки не затрагиваются |
| **Технически** | `NullPointerException` при кодировании: `CustomPayload$1.getCodec()` возвращает `null` для незарегистрированного id |
| **Статус** | ✅ **исправлено в [`56.1.0-alfa`](../56.1.0-alfa/)** — добавлена регистрация в `RPGACommonMod` |

**Латентный баг:** `MobSpawnSyncPayload` (обратная синхронизация) в 51.4-beta
объявлен, но сервер его нигде не отправляет — поэтому вживую **не проявляется**.
Если добавить отправку — будет такой же краш.

## 💥 Баг №2 — Перевод денег крашит игру

| | |
|---|---|
| **Где** | `item/RPGAMoneyItem.java:144-150` (объявление), `:197` (отправка) |
| **Что** | `MoneyTransferPayload`, id `rp-mxtr-rpga:money_transfer` — единственный пейлоад мода, объявленный не в `RPGAPayloads.java` |
| **Почему ломается** | Реализует `CustomPayload`, но **не зарегистрирован** в `PayloadTypeRegistry`. Остальные пейлоады зарегистрированы в `RPGACommonMod.java` — этот пропущен |
| **Что видит игрок** | Игрок открывает экран денег и жмёт **«Перевести»** или **«Снять»** → игра падает → **клиент вылетает на рабочий стол** |
| **Деньги** | **не списываются и не переводятся** |
| **Кто страдает** | только отправляющий игрок |
| **Статус** | ⛔ не исправлено ни в одной версии |

**Как избежать:** не переводить деньги через GUI. Баланс — командой
`/rpga setbalance <игрок> <сумма>` — см. [ADMIN-GUIDE.md](../../docs/ADMIN-GUIDE.md).

## 🐛 Баги без вылета

| Баг | Что происходит с игроком | Вылет? |
|---|---|:-:|
| 🔴 **Ранг «Смотрителя» показывает «Неизвестно»** | Фракция `warden` есть, но её ранг не прописан в `FactionRankSystem`. Игрок видит **«Неизвестно»** вместо ранга | ❌ Нет |
| 🔴 **Навигационные точки исчезают после рестарта** | Точки работают, но список живёт **только в оперативной памяти** (`RPGAServerMod.java:6252`). После рестарта сервера **все точки пропадают** | ❌ Нет |
| 🟡 **Заявка в друзья не отправляется** | Игрок жмёт «добавить в друзья» — заявка уходит не на ту сторону. Игрок видит пустоту, у другого игрока заявка не появляется | ❌ Нет |

**Обходной путь для навигации:** создавать точки заново после каждого рестарта
или использовать **блоки `navigation_point`** — они хранятся в мире.
