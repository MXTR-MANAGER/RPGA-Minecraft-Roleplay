## 🐛 Баги этой версии

💥 **Самая нестабильная версия из всех: 2 бага с вылетом клиента.** Читайте
до установки — особенно если вы администратор сервера.

| Баг | Что происходит с игроком | Вылет? |
|---|---|:-:|
| 🔴 **Настройки спавна мобов крашат админа** | Админ открывает **«Настройки спавна мобов»** (экран добавлен именно в этой версии) или нажимает кнопку в админ-панели. Мод отправляет пакет настроек, но он **не зарегистрирован в системе пейлоадов** → **клиент администратора вылетает на рабочий стол**. Обычные игроки при этом не страдают. Настройки применить невозможно — экран каждый раз убивает игру. | 💥 **ДА — краш клиента (админ)** |
| 🔴 **Перевод денег крашит игру** | Игрок открывает экран денег и жмёт **«Перевести»** или **«Снять»**. Пакет перевода **не зарегистрирован** → игра падает, **клиент вылетает на рабочий стол**. Деньги **не списываются**. | 💥 **ДА — краш клиента** |
| 🔴 Ранг «Смотрителя» показывает «Неизвестно» | Фракция `warden` есть, но её ранг не прописан в системе титулов. Игрок видит **«Неизвестно»** вместо ранга — в чате, в форме, в списке игроков. | ❌ Нет |
| 🔴 Навигационные точки теряются при рестарте | Точки навигации видны всем, но хранятся **только в оперативной памяти**. После перезапуска сервера **все точки исчезают** — расставлять заново. | ❌ Нет |
| 🟡 Заявка в друзья не отправляется | Игрок жмёт «добавить в друзья» — заявка уходит не на ту сторону. Игрок видит пустоту, у другого игрока заявка не появляется. | ❌ Нет |
| 💡 `MobSpawnSyncPayload` (обратная синхронизация) | Пакет объявлен, но сервер его нигде не отправляет — поэтому вживую **не проявляется**. Если добавить отправку — будет такой же краш, как у настроек. | ❌ Нет (латентный) |

> 🔍 Проверено по байткоду `RP-MXTR-RPGA-51.4-beta.jar`.
> ⛔ **Не ставьте 51.4-beta на боевой сервер** — админ-панель в ней убивает игру.
> ✅ Обе проблемы с пакетами исправлены в [56.1.0-alfa](../56.1.0-alfa/).

Подробности по всем версиям — в [KNOWN-ISSUES.md](../../docs/KNOWN-ISSUES.md).

## 🆕 Что нового в 51.4-beta

### 🎮 Настройки спавна мобов

Новый экран настройки того, **какие мобы спавнятся в мире и в каком количестве**.

| Новый класс | Назначение |
|---|---|
| `MobSpawnSettingsScreen` | Экран настройки спавна мобов |
| `MobSpawnCfgPayload` | Сохранение конфигурации спавна |
| `MobSpawnSyncPayload` | Синхронизация настройки |

### 🔭 Бинокль с приближением

Миксин **`RPGABinocularFovMixin`** — при использовании бинокля изменяется
**поле зрения камеры**, давая эффект оптического приближения. Раньше бинокль
был обычным предметом без эффекта.

### 🎨 Полный комплект текстур формы — 42 новые текстуры

Каждая часть формы теперь имеет **отдельную текстуру** высочайшего качества.

| Форма | Шлем / Головной убор | Нагрудник | Штаны | Ботинки |
|---|:---:|:---:|:---:|:---:|
| **MIL** | ✅ | ✅ | ✅ | ✅ |
| **ДПС** | ✅ | ✅ | ✅ | ✅ |
| **ФСБ** | ✅ | ✅ | ✅ | ✅ |
| **ФСО** | ✅ | ✅ | ✅ | ✅ |
| **Медицинская** | ✅ | ✅ | ✅ | ✅ |

**Также добавлены текстуры:**

| Категория | Состав |
|---|---|
| 🔒 Тюрьма | Карточка дверей, блок точки появления, инструмент тюремщика |
| 🔑 Замки | Замок, ключ, замок Pro |
| 📦 Ящики с патронами | Стальной, латунный, красный |
| 🔫 Типы патронов | Медь, латунь, свинец, зелёный, синий, красный |
| 🏗 Прочее | Спец-бочка фракции, блок пожара, дорожный конус, навигационная точка |
| 📱 Предметы | Смартфон РГА, яйцо спавна NPC |
| 💨 Гранаты | Дымовая быстрая / средняя / долгая |
