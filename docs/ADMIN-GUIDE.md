## 1. Установка на сервер

### Требования

| Компонент | Версия |
|---|---|
| Minecraft | **1.21.10** |
| Fabric Loader | **0.16.9+** (проверено 0.19.3) |
| Fabric API | под 1.21.10 (проверено 0.138.4+1.21.10) |
| Java | **21** |
| Сервер | Fabric Dedicated Server |

### Шаги

1. Положите в папку `mods` сервера:
   - `fabric-api-*.jar`
   - `RP-MXTR-RPGA-<версия>.jar`
2. **Перезапустите сервер.** Мод при первом запуске создаст 12 файлов конфигурации.
3. Выдайте себе ранг командой из консоли (раздел 3).
4. Проверьте: `/rpga rank` в чате должен показать ваш ранг.

### Что ставить на сервер

| Версия | Статус | Рекомендация |
|---|---|---|
| **56.1.0-alfa** 🌐 | **версия сервера RPGA** | ✅ **Рекомендуется.** Звуки, баг-репорты, тюрьма v51.5, замки v51.6, паспорт |
| 30.0.2 | стабильный релиз без звуков | ✅ Подходит, если не нужны звуки и баг-репорты |
| 51.3-beta / 51.4-beta | 🧪 **та же версия, что и альфа** | 🕳️ **Пусто.** Не ставить ни на сервер, ни в одиночку |
| 30.0.1 | быв. версия сервера RPGA | ⛔ Устарела (12.09 — 03.10.2026) |
| 1.0.0 / 12.1.0 | старые | ⛔ Устарели, нет фикса тюрьмы, замков, Даркнета |

> 🧪 **Бета = альфа.** 51.3 и 51.4 — черновики той же линии: весь их код вошёл
> в 56.1.0-alfa. Ни одной фичи беты там нет, поэтому ни на сервере, ни в
> одиночной игре они не дают ничего. Подробнее — в
> [**VERSION-GUIDE.md**](../VERSION-GUIDE.md#-почему-остальные-версии-устарели).

> ⚠️ **Жёсткое правило:** у **всех** игроков должна стоять **та же версия** мода, что и на сервере. Мод активно обменивается пакетами, несовпадение версий = потеря связи, зависание, «пропадание» игроков.

### Отдельно про клиент

Not Enough Animations уже вшит внутрь jar мода — отдельно ставить не нужно.

## 2. Ранги

Ранги задаются **числом**. Полный список:

| Ранг | Имя | Для кого |
|:---:|---|---|
| `1` | **Полный доступ** | Главный администратор. Всё разрешено |
| `2` | **Модератор** | Опытный модератор. Бан, анбан, выдача, убийство, фриз, телепорт, инвентарь |
| `3` | **Младший модератор** | Новичок. Бан, мут, телепорт, инвентарь, фриз, репорты |
| `4` | **Хелпер (наблюдатель)** | Смотрит за порядком. Режим наблюдателя |
| `5` | **Лидер фракции** | Управляет своей фракцией |
| `15` | **Владелец** | Владелец мира, полный доступ |
| `16` | **Билдер** | Строитель, полный доступ |
| `0` | Нет (обычный игрок) | Права отсутствуют |

### Приоритет рангов

Когда два администратора действуют друг на друга, срабатывает правило приоритета:

```
1 (Полный) → 15 (Владелец) → 16 (Билдер) → 2 (Модер) → 3 (Мл. модер) → 4 (Хелпер) → 5 (Лидер)
```

- На **обычного игрока** (ранг 0) может действовать кто угодно из админов.
- **Равные не могут действовать друг на друга.**
- **Младший не может трогать старшего.**

Это защищает от конфликтов между администраторами.

## 3. Выдача рангов

### Команда

В **консоли сервера** (не в чате!):

```
rpga admin <игрок> <ранг>
```

> Команда называется `rpga admin`, а не `/rpga admin`. В консоли слэш и префикс `/` не нужны.

### Ограничения

1. ❌ **Только из консоли.** В чате команда не сработает.
2. ❌ **Только владелец мира** (ранг 1) может выдавать ранги.
3. ✅ Допустимые ранги: `1`, `1.5` (=15), `1.6` (=16), `2`, `3`, `4`, `5`.

### Примеры

```
rpga admin Steve 1
rpga admin Steve 2
rpga admin Alex 3
rpga admin Anna 5
```

### Что будет, если нарушить правила

| Ситуация | Сообщение |
|---|---|
| Выдать ранг из чата | `На сервере ранги выдаются только из консоли.` |
| Не владелец мира | `Только владелец мира может выдавать ранги.` |
| Неверный номер ранга | `Допустимые ранги: 1, 1.5 (15), 1.6 (16), 2, 3, 4, 5.` |

### Где хранится

`config/rpga_server.json` → массив `admins`:

```json
{
  "admins": [
    { "uuid": "ваш-uuid", "name": "Steve", "rank": 1 }
  ],
  "player_factions": {}
}
```

> UUID можно узнать командой `whitelist` или через сайт `mcuuid.net` по нику.

## 5. Все команды

### Ввод в чате (все команды начинаются с `/rpga`)

| Команда | Пермиссия | Пример | Что делает |
|---|---|---|---|
| `/rpga menu` | ур. 3 | `/rpga menu` | Открыть меню RPGA (профиль, магазин, работа, жалобы) |
| `/rpga admin` | ур. 3 | `/rpga admin` | Открыть админ-интерфейс |
| `/rpga adminpanel` | любой админ | `/rpga adminpanel` | Открыть полную админ-панель |
| `/rpga report <игрок> <причина>` | нет | `/rpga report Griefer грязный спавн` | Подать жалобу |
| `/rpga balance` | нет | `/rpga balance` | Показать баланс |
| `/rpga accept_call <ник>` | нет | `/rpga accept_call Steve` | Принять вызов |
| `/rpga rank` | нет | `/rpga rank` | Показать свой ранг |
| `/rpga admins` | нет | `/rpga admins` | Список всех администраторов |
| `/rpga resetpass <ник>` | — | `/rpga resetpass Steve` | Сбросить пароль игрока |
| `/rpga setbalance <игрок> <сумма>` | ур. 3 | `/rpga setbalance Steve 5000` | Установить баланс |
| `/rpga thirst <игрок> <0-20>` | ур. 3 | `/rpga thirst Steve 20` | Установить жажду |
| `/rpga ban <игрок>` | 1, 2, 3 | `/rpga ban Griefer` | Забанить |
| `/rpga unban <игрок>` | 1, 2 | `/rpga unban Griefer` | Разбанить |
| `/rpga kill <игрок>` | 1, 2 | `/rpga kill Griefer` | Убить игрока |
| `/rpga give <предмет>` | 1, 2 | `/rpga give medkit` | Выдать предмет себе |
| `/rpga give <предмет> <игрок> <предмет> <кол-во>` | 1, 2 | `/rpga give ak47 Steve ak47 1` | Выдать предмет игроку |
| `/rpga mute <игрок>` | 1, 3 | `/rpga mute Griefer` | Замутить на **10 минут** (по умолчанию) |
| `/rpga mute <игрок> <минуты>` | 1, 3 | `/rpga mute Griefer 60` | Замутить на 60 минут |
| `/rpga unmute <игрок>` | 1, 3 | `/rpga unmute Griefer` | Снять мут |
| `/rpga spec` | 1, 4 | `/rpga spec` | Включить/выключить наблюдателя |
| `/rpga faction info` | нет | `/rpga faction info` | Информация о фракции |
| `/rpga faction members` | нет | `/rpga faction members` | Состав фракции |
| `/rpga faction kick <игрок>` | 1, 5 | `/rpga faction kick Steve` | Исключить из фракции |

### Ограничения команд

- `/rpga mute <игрок> <минуты>` — от **1 до 10 080** минут (максимум 7 дней). Без параметра — 10 минут.
- `/rpga give` — количество от **1 до 64**.
- `/rpga report <причина>` — причина вводится целиком до конца строки (можно писать много текста).
- ⚠️ **Особенность `/rpga give`:** синтаксис — `/rpga give <предмет> <игрок> <предмет> <кол-во>`. В коде первый аргумент-предмет **не используется** (используется второй). Можно писать любой, но для читаемости ставьте одинаковые.

### Клиентская команда

Вводится в чат **на клиенте** (не на сервере):

```
/rpga_accept_call <ник>
```

Принимает входящий вызов. Удобно, если игрок не может открыть телефон.

### Команда в консоли сервера

```
rpga admin <игрок> <ранг>
```

Только владелец мира. Подробнее — [раздел 3](#3-выдача-рангов).

## 7. Файлы конфигурации

После первого запуска мод создаёт **12 файлов**. Меняйте при выключенном сервере.

### Основные (в папке `config/`)

| Файл | Что внутри | Когда менять |
|---|---|---|
| **`rpga_server.json`** | `admins[]` (uuid, name, rank), `player_factions{}` | Выдача рангов и фракций вручную |
| **`rpga-admins.json`** | Ранги, муты, магазин, депутаты, лидеры, заморозка | Прямое редактирование санкций и магазина |
| **`rpga_players.json`** | Профили игроков: деньги, документы, жажда, розыск | Восстановление или правка профиля |
| **`rpga_players.json.bak`** | Резервная копия профилей | Не трогать, автобэкап |
| **`rpga_wallets.json`** | Балансы игроков | Массовая правка балансов |
| **`rpga_passwords.json`** | Хеши паролей игроков | ⚠️ **Не редактировать вручную** |
| **`rpga_profiles.json`** | Анкеты игроков (ФИО и т.д.) | Правка анкет |
| **`rpga-cars.json`** | Каталог машин: id, name, brand, price, command | Свой автопарк |
| **`rpga-jail.json`** | Камеры, точки выхода, зона, заключённые | Настройка тюрьмы вручную |
| **`rpga-locks.json`** | Все замки на карте, коды | Коды замков |
| **`rpga-config.json`** | Порох, плавка, производительность | Баланс крафта и производительности |
| **`rpga-ui.json`** | Настройки интерфейса на клиенте | Размер и положение элементов |
| **`rpga-bugs.json`** 🌐 | **База баг-репортов игроков** (до 500 записей) | Разбор обращений игроков |
| **`rpga-bugreport.json`** | Адрес приёма баг-репортов (клиентский) | Свой сервер сбора репортов |

### Структура `rpga-bugs.json` (новая в 56.1.0-alfa)

```json
{
  "bugs": [
    {
      "id": "uuid-под-стабильности",
      "createdAt": 1760000000000,
      "name": "Ник игрока",
      "category": "Геймплей",
      "description": "Описание бага",
      "modVersion": "v56.1.0_alfa",
      "minecraftVersion": "1.21.10",
      "environment": "сервер RPGA",
      "player": "uuid-игрока"
    }
  ]
}
```

| Поле | Значение |
|---|---|
| `id` | Уникальный идентификатор репорта |
| `createdAt` | Время отправки (миллисекунды) |
| `category` | Одна из 7 категорий: Геймплей · Краш · Графика · Сетевая · Звук · Глейч · Другое |
| `description` | До **2000 символов** |
| `environment` | Одиночка / сервер RPGA / свой сервер |
| `player` | UUID игрока, отправившего репорт |

> 📥 **Как попадают репорты:** игрок жмёт «Баг-репорт» в меню паузы
> (`GameMenuScreenMixin`) или на титульном экране (`TitleScreenMixin`).
> В игре пакет уходит на сервер сразу; с титульного экрана репорт кладётся
> в очередь `config/rpga-bug-queue/bug-*.json` и уходит при подключении
> (первая попытка — на 200-м тике, далее каждые 1200 тиков).
>
> ⚠️ **Известная проблема:** при отправке с титульного экрана игрок видит
> «Связи нет — репорт сохранён», хотя репорт **уходит**. См.
> [KNOWN-ISSUES.md](KNOWN-ISSUES.md#3-баг-репорт-говорит-не-успешно-но-уходит).

### Мировые (в папке мира)

| Файл | Что внутри |
|---|---|
| **`rpga-npcs.json`** | Все NPC: фракция, работа, торговец, экипировка |
| **`rpga-barrel-storages.json`** | Содержимое фракционных бочек |

### Структура `rpga-locks.json` (обновлена в 56.1.0-alfa)

> 🔒 **Замки теперь сохраняются на диск** — раньше они терялись при рестарте.

```json
{
  "locks": [
    {
      "pos": "123,64,-456",
      "lock_id": "lock_pro",
      "owner": "Ник владельца",
      "faction": "fsb",
      "mode": "keycard"
    }
  ]
}
```

| Поле | Значение |
|---|---|
| `pos` | Координаты блока замка в формате `x,y,z` |
| `lock_id` | Тип замка: `lock` · `lock_key` · `lock_pro` |
| `owner` | Ник владельца замка |
| `faction` | Фракция-владелец (`fsb`, `fso`, `dps`, `mchs`, `med`, `sk`, `army`) |
| `mode` | Режим доступа: ключ · карточка · отмычка |

> 💡 Для настройки замков в игре есть экран `LockActionsScreen` и подсказка на
> HUD (`client/LockHintRenderer.java`).

### Настройки пороха и крафта (`rpga-config.json`)

| Параметр | По умолчанию | Что делает |
|---|:---:|---|
| `oreToGunpowderChance` | 0.35 | Шанс выхода пороха из руды |
| `redstoneLongLoadedChance` | 0.5 | Шанс усиленной зарядки (работает как верстак) |
| `longLoadedTicks` | 6000 | Время усиленной зарядки (тики, 300 = 15 сек) |
| `cauldronTimeTicks` | 300 | Время обработки в котле |
| `furnaceExplodeChance` | 0.9 | Шанс взрыва при неправильной плавке |
| `throttleStatEffects` | true | Оптимизация эффектов |
| `statEffectIntervalTicks` | 10 | Интервал обновления эффектов (тики) |
| `bedrockToleranceY` | 8 | Допуск по Y для бедрока (0–64) |

> ⚠️ **Не копируйте эти параметры между версиями мода** без проверки — набор может отличаться.

## 8. Настройка тюрьмы

Тюрьма настраивается **инструментом в игре** (быстрее и надёжнее, чем правка JSON).

### Шаг 1. Получите инструмент

```
/rpga give jail_tool
```

### Шаг 2. Отметьте камеры

Возьмите `jail_tool` в руку, подойдите к каждой камере и отметьте. Инструмент запоминает координаты блоков.

### Шаг 3. Задайте точку выхода

Инструментом отметьте блок, куда попадает заключённый при освобождении.

### Шаг 4. Задайте зону тюрьмы

Отметьте два противоположных угла — мод запомнит границы зоны.

### Шаг 5. Пометьте служебные блоки

Блоки `system_control` (системные контролеры) внутри зоны отмечаются отдельно.

### Что где хранится

Всё сохраняется в `config/rpga-jail.json` автоматически:

```json
{
  "next_id": 1,
  "spawn_pos": 0,
  "exit_pos": 0,
  "zone1": 0,
  "zone2": 0,
  "cells": [
    {
      "id": 1,
      "ax": 100, "ay": 64, "az": 200,
      "bx": 104, "by": 68, "bz": 204,
      "prisoner": null,
      "jailed_at": 0,
      "jail_until": 0
    }
  ],
  "guarded": [],
  "cell_spawns": [],
  "system_controls": []
}
```

| Поле | Значение |
|---|---|
| `spawn_pos` | Точка спавна заключённого |
| `exit_pos` | Точка выхода при освобождении |
| `zone1`, `zone2` | Два угла зоны тюрьмы |
| `cells[]` | Камеры с координатами и данными заключённого |
| `guarded[]` | Спецблоки охраны |
| `cell_spawns[]` | Индивидуальные спавны для камер |
| `system_controls[]` | Помеченные системные блоки |

### Предметы администратора тюрьмы

| Предмет | Назначение |
|---|---|
| `jail_tool` | Инструмент настройки |
| `jail_doorcard` | Карточка двери камеры |
| `jail_spawn_block` | Блок точки спавна заключённого |
| `jail_exit_block` | Блок точки выхода |
| `system_control` | Системный контролер |

### Сроки заключения

Общее правило: **срок = звёзды × 5 минут**. Отдельные нарушения задают срок вручную. Таймер идёт в реальном времени и сохраняется в JSON — переживает перезапуск сервера.

## 9. Транспорт

### Файл `config/rpga_cars.json`

```json
{
  "cars": [
    { "id": "uaz_patriot", "name": "UAZ Patriot", "brand": "UAZ", "price": 25000, "command": "give {player} minecraft:car 1" },
    { "id": "lada_granta", "name": "LADA Granta", "brand": "LADA", "price": 8000, "command": "give {player} minecraft:car 1" },
    { "id": "gazelle", "name": "GAZelle Business", "brand": "GAZ", "price": 15000, "command": "give {player} minecraft:car 1" }
  ]
}
```

| Поле | Что делает |
|---|---|
| `id` | Уникальный идентификатор модели |
| `name` | Отображаемое название |
| `brand` | Марка (группировка в каталоге) |
| `price` | Цена в игровых долларах |
| `command` | Команда, которая выдаёт машину (опционально). `{player}` — ник игрока |

### Чтобы изменить

1. Остановите сервер.
2. Отредактируйте `config/rpga_cars.json`.
3. Запустите сервер заново.

Мод перезаписывает файл при старте, поэтому правки в игре не сохранятся — редактируйте только при выключенном сервере.

### Про модели машин

3D-модели и текстуры машин **вшиты внутрь jar мода** (`assets/rp-mxtr-rpga/textures/3d/`). Мод не читает OBJ-модели с диска, поэтому:

- ✅ Можно менять **цены, названия, марки** через `rpga_cars.json` — это работает.
- ❌ Нельзя добавить **новую** 3D-модель простой правкой JSON — для этого нужна пересборка мода.

> Если добавляете новую машину в каталог, `id` должен совпадать с id уже вшитой модели, иначе позиция в каталоге будет пустой. Полный список id можно посмотреть в `rpga_cars.json` после первого запуска сервера.

{
  "admins": [],

    "uuid-игрока-1": "fsb",
    "uuid-игрока-2": "med"
  }

| Фракция | Служба |
|---|---|
| `fsb` | полиция |
| `fso` | полиция |
| `dps` | полиция |
| `sk` | полиция |
| `med` | медики |
| `mchs` | МЧС |
| `army` | армия |
| `auto` | автомобилисты |

### Выдать фракцию из панели

**Админ-панель → Выдача фракции** — проще, чем править JSON.

### NPC

Хранятся в мировом файле `rpga-npcs.json`:

| Параметр | Значения |
|---|---|
| Фракции NPC | `fsb`, `fso`, `dps`, `mchs`, `med`, `sk`, `army`, `auto` |

### Управление NPC из панели

- **Спавн NPC** — создать нового NPC с фракцией и работой.
- **Настройка мобов** — параметры спавна, размер, здоровье.

> ⚠️ **Навигационные точки не сохраняются.** Точки, созданные в Навигаторе телефона, живут только в памяти и **исчезают при перезапуске сервера**. Это известная проблема — [KNOWN-ISSUES.md](KNOWN-ISSUES.md).

## 11. Бэкап и восстановление

### Что обязательно копировать

**Папка `config/`:**
```
rpga_server.json        ← админы и фракции
rpga-admins.json        ← муты, магазин, депутаты
rpga_players.json       ← профили игроков (документы, деньги, жажда)
rpga_players.json.bak   ← резервная копия
rpga_wallets.json       ← балансы
rpga_profiles.json      ← анкеты
rpga_passwords.json     ← пароли
rpga-cars.json          ← каталог машин
rpga-jail.json          ← тюрьма
rpga-locks.json         ← замки
rpga-config.json        ← настройки крафта
```

**Папка мира:**
```
rpga-npcs.json              ← NPC
rpga-barrel-storages.json   ← фракционные бочки
```

### Простой скрипт бэкапа

```bash
#!/bin/bash
# backup_rpga.sh
DATE=$(date +%Y-%m-%d_%H-%M)
mkdir -p "backups/$DATE"
cp config/rpga-*.json "backups/$DATE/" 2>/dev/null
cp <папка-мира>/rpga-*.json "backups/$DATE/" 2>/dev/null
echo "Бэкап RPGA создан: backups/$DATE"
```

### Восстановление

1. Остановите сервер.
2. Замените файлы в `config/` и в папке мира файлами из бэкапа.
3. Запустите сервер.

### Автобэкап профилей

Мод сам создаёт `rpga_players.json.bak` при перезаписи. Не удаляйте этот файл.

## 12. Типовые задачи

### Выдать предмет игроку

```
/rpga give ak47 Steve ak47 1
```

Формат: **предмет → кому → предмет → количество**. Можно выдать себе, оставив поле «кому» пустым.

### Выдать предмет себе

```
/rpga give medkit
```

### Выдать паспорт (первый документ)

```
/rpga give passport Steve passport 1
```

### Забанить игрока

```
/rpga ban Griefer
```

Мод отправит ему сообщение и отключит от сервера. Разбан: `/rpga unban Griefer`.

### Замутить игрока

```
/rpga mute Griefer          ← на 10 минут (по умолчанию)
/rpga mute Griefer 60       ← на 60 минут
/rpga unmute Griefer        ← снять мут
```

> ⚠️ Без параметра минут мут ставится на **10 минут**, а не навсегда. Для постоянного мута указывайте большое число, максимум — `10080` (7 суток).

### Сбросить пароль игрока

```
/rpga resetpass Steve
```

Если у игрока нет пароля, мод сообщит об этом.

### Настроить тюрьму

1. `/rpga give jail_tool`
2. Отметить камеры, точку выхода, зону, служебные блоки.
3. Проверить `config/rpga-jail.json`.

### Сбросить баланс игрока

```
/rpga setbalance Steve 0
```

### Выдать жажду

```
/rpga thirst Steve 20
```

Значение от `0` до `20`.

### Назначить лидера фракции

**Админ-панель → Лидеры фракций** (ранг 1 или 5).

### Сделать себя админом

1. Узнайте свой UUID (сайт `mcuuid.net` по нику).
2. В консоли: `rpga admin <ник> 1`
3. Перезайдите на сервер, проверьте `/rpga rank`.

### Добавить машину в каталог

1. Остановите сервер.
2. Отредактируйте `config/rpga_cars.json`.
3. Запустите сервер.
