## 1. Установка

### Требования

| Компонент | Версия |
|---|---|
| Minecraft | **1.21.10** |
| Fabric Loader | **0.16.9** или новее (проверено на 0.19.3) |
| Fabric API | любая версия под 1.21.10 (проверено 0.138.4+1.21.10) |
| Java | **21** |

### Шаги

1. Установите **Fabric Loader** для Minecraft 1.21.10.
2. Положите в папку `mods`:
   - `fabric-api-*.jar`
   - `RP-MXTR-RPGA-<версия>.jar` ← файл мода
3. Запустите клиент, дождитесь главного меню (показывается заставка мода).
4. Зайдите на сервер. Если вы **администратор** — см. [ADMIN-GUIDE.md](ADMIN-GUIDE.md#3-выдача-рангов).

> **Не нужно** отдельно ставить Not Enough Animations — он уже вшит внутрь jar мода.

### Одиночная игра

Сервер не нужен. Ставьте мод в `mods` обычного клиента и играйте в одиночку — работает всё, включая NPC, тюрьму и админ-панель (выдайте себе ранг в консоли мира командой `rpga admin <ник>`).

## 2. Первый вход и пароль

При входе на защищённую зону появляется окно авторизации.

| Кнопка | Что делает |
|---|---|
| **Войти** | ввести пароль от аккаунта |
| **Создать пароль** | придумать пароль (только при первом входе) |
| **Забыли пароль?** | сбросить пароль |

> ⚠️ **До ввода пароля мод блокирует ВСЁ**: ни одной команды не пройдёт, ни одного действия не выполнится. Это защита аккаунта — так задумано. Если окно не появилось, а действия заблокированы — нажмите `Esc` или откройте чат (`T`), мод покажет окно ввода пароля.

### Забыли пароль

- **Самостоятельно:** команда `/rpga resetpass <ник>` — сбрасывает пароль игрока.
- **Администратору:** та же команда, см. [ADMIN-GUIDE.md](ADMIN-GUIDE.md#12-типовые-задачи).

## 3. Управление

Мод добавляет **3 клавиши**. Меняются в стандартных настройках управления Minecraft, категория **«Разное»** (Misc).

| Клавиша | Действие | Что это |
|:---:|---|---|
| **`R`** | Перезарядка | Перезаряжает оружие из руки |
| **`H`** | Сесть | Сесть в машину, кресло, на блок |
| **`F`** | Фонарик | Включить/выключить фонарик из инвентаря |

### Экраны, которые можно открыть

| Как открыть | Что открывается |
|---|---|
| Кнопка в меню паузы | 🎓 **Гайд по моду** (этот же текст, внутри игры) |
| Кнопка в меню паузы | 🎨 **Настройки интерфейса** RPGA |
| Кнопка в главном меню игры | ✨ **Заставка** RPGA |
| Кнопка в инвентаре | 📋 **Меню RPGA** — профиль, жалобы, магазин, работа, обмен |
| Взять в руку предмет `RP-MXTR-RPGA:rpga_phone` и нажать | 📱 **Телефон** |
| Команда `/rpga menu` (админ, ур. 3) | 📋 Меню RPGA |

## 5. Выживание: жажда, температура, голод

### Жажда

- Шкала **0–20** (как сердца, но наоборот: чем больше — тем лучше).
- Падает понемногу — пересчёт каждые 20 тиков (примерно раз в секунду).
- На **0** — начинается обезвоживание: урон, замедление, темнота на экране.
- **Пополнить:** вода в бутылке, сок, кола, молоко, энергетик, суп.
- **Админ:** команда `/rpga thirst <игрок> <0-20>`.

### Температура

Растёт/падает в зависимости от биома, погоды, времени суток, брони и пребывания рядом с огнём.
- Слишком холодно → замедление и урон.
- Слишком жарко → жажда падает вдвое быстрее.
- Защита: тёплая одежда, бронежилет, укрытие, огонь.

### Голод

Работает через ванильный голод, но усилен модом: бег, драка и холод тратят сытость быстрее.
- Еда мода: бургер, жареное мясо, картошка фри, яйцо, рыба, суп, молоко, сок, кола, энергетик.

## 7. Документы и удостоверения

Документы — предметы, которые открывают свой экран при использовании. Их выдаёт администрация.

| Предмет | Кто пользуется | Что открывает |
|---|---|---|
| **Паспорт** (`passport`) | все | анкету; можно запросить документы |
| **Водительское удостоверение** (`driver_license`) | водители | права с категориями |
| **Разрешение на оружие** (`weapon_permit`) | стрелки | разрешение, можно открыть/закрыть |
| **Штрафная квитанция** (`fine_note`) | нарушители | текст штрафа |
| **Улика** (`evidence_bag`) | следователи | улика, её можно спрятать — снижает розыск |
| **Контрабанда** (`contraband`) | нарушители | перевозка запрещённого |
| **Деньги** (`money_stack`) | все | пачка денег, можно передать |
| **Фото** (`photo`) | следователи | фотографию (галерея камеры) |
| **Блокнот** (`notepad`) + **ручка** (`pen`) | все | записи |
| **Рюкзак** (`backpack`) | все | дополнительный инвентарь |

> 📌 **Паспорт** — базовый документ. Без него остальные документы не выдадут.
> Спрятанная улика снижает розыск на **2 звезды** и пишет в чат: `Улики скрыты. Розыск снижен на 2★.`

## 8. Телефон и его приложения

Предмет **`rga_phone`** (смартфон). Возьмите в руку и нажмите — откроется экран телефона.

### Базовые приложения (есть всегда)

| Иконка | Приложение | Что умеет |
|---|---|---|
| 💬 | **Чат** | список чатов → личные сообщения (Enter — отправить) |
| 🚨 | **112 Службы** | вызов экстренных служб |
| 🏦 | **Банк** | баланс, переводы, пополнение |
| 👤 | **Профиль** | своя анкета и статистика |
| 🚗 | **Машины** | каталог, покупка, вход в свою машину |
| 🧑‍🤝‍🧑 | **Друзья** | список, заявки, личные чаты |

### Условные приложения (появляются при условиях)

| Иконка | Приложение | Когда доступно |
|---|---|---|
| 👮 | **Полиция** | только если ваша фракция — полицейская (ФСБ, ФСО, ДПС, СК) |
| 🕶️ | **Даркнет** | только если вы в розыске (`darknetWanted`) — чёрный рынок подполья |

### Второй экран телефона

| Пункт | Что делает |
|---|---|
| **Контакты** | список всех игроков, из него — позвонить |
| **Вызвать** | набрать номер вручную |
| **Сообщения** | SMS |
| **Навигатор** | точки на карте, создание своих точек |
| **Настройки** | *скоро появится* (заглушка в коде) |
| **Выключить** | сбросить трубку |

### Экстренный вызов

В приложении **112 Службы** выбираешь: полиция / скорая помощь / МЧС / все службы.
На сервере также принимается прямой номер **112**.

### Полиция и Даркнет

- **Полиция** — доступ к базе разыскиваемых, реестру, рабочим инструментам.
- **Даркнет** — подпольный рынок, доступен **только игрокам в розыске**.

## 12. Транспорт

3D-машины с физикой. В моде **26 моделей**.

### Как купить и сесть

1. Телефон → **Машины** → каталог.
2. Купил машину — она твоя.
3. Подойди к машине → нажми **`H`** («Сесть») или кликни по ней.
4. Управление — стандартное (WASD).

### Возможности

- Каталог с ценами и брендами
- Покупка за игровые деньги
- Фракционные бочки-склады
- Топливо/расход — зависит от конфигурации сервера
- Машины NPC (продавец `dealer`)

## 13. NPC

NPC — живые персонажи, которые ходят, работают и торгуют.

### Спавн (одиночная игра / админ)

1. Креативный таб **RPGA**.
2. Яйцо NPC (`npc_spawn_egg`).
3. Поставь на землю.
4. ПКМ по NPC → панель взаимодействия.

### Панель NPC

| Пункт | Что делает |
|---|---|
| **Работа** | назначить NPC на работу |
| **Настройки** | фракция, экипировка, торговец |
| **Магазин** | свой товар и цены |
| **Тюрьма** | взять заключённого / настроить камеры |
| **Покупка** | интерфейс покупки у этого NPC |

### Роли торговцев

`shop` (магазин), `blackmarket` (чёрный рынок), `gunshop` (оружейный), `dealer` (автомобили), `building` (строительный).

### Фракции NPC

ФСБ, ФСО, ДПС, МЧС, Мед, СК, Армия, Авто.

## 14. Тюрьма и розыск

### Розыск (звёзды)

| Причина | Звёзды | Срок |
|---|---|---|
| Убийство сотрудника полиции | ⭐⭐⭐⭐⭐ | 15 минут |
| Убийство игрока | ⭐⭐⭐ | 10 минут |
| Нападение на NPC | ⭐ / ⭐⭐ | по ситуации |
| Грабёж | ⭐ | 5 минут |
| Спрятать улику | — | **снимает 2 звезды** |

Общее правило: **срок = звёзды × 5 минут**. Некоторые нарушения задают срок вручную.

Свой розыск видно в **Профиле** (приложение в телефоне).

### Тюрьма

Заключение назначает администрация через **инструмент тюрьмы** (`jail_tool`):

- отмечаются камеры (блоки камеры)
- точка выхода при освобождении
- зона тюрьмы
- служебные блоки (`system_control`)

Заключённый видит **экран тюрьмы** с таймером. По достижении срока он освобождается автоматически.

### Штрафы

**Штрафная квитанция** (`fine_note`) — выписывается на игрока, открывается как документ. Оплачивается деньгами.

## 15. Жалобы и вызовы

### Подать жалобу

Меню RPGA → **Жалобы** → **Подать**, или командой:

```
/rpga report <игрок> <причина>
```

Жалоба уходит всем администраторам уровня 3 в чат.

### Ответить на вызов

Входящий вызов от NPC или игрока: команда

```
/rpga_accept_call <ник>
```

### Экстренные службы

Телефон → **112 Службы** → полиция / скорая / МЧС / все. Можно и просто набрать **112**.

## 17. Команды игрока

Все команды начинаются с `/rpga`. Вводить нужно в чате.

| Команда | Что делает |
|---|---|
| `/rpga balance` | показать баланс |
| `/rpga rank` | показать свой ранг и статус |
| `/rpga report <игрок> <причина>` | подать жалобу |
| `/rpga faction info` | информация о фракции |
| `/rpga faction members` | состав фракции |
| `/rpga accept_call <ник>` | принять вызов |

## 18. Полезные советы

1. **Всегда вводите пароль при входе.** Без этого мод блокирует игру.
2. **Наведите курсор на предмет**, чтобы увидеть описание — мод показывает патрон, урон, расход сытости и т.д.
3. **Держите пистолет в подсумке** (`Q`/прокрутка) — так не теряется при смерти.
4. **Не ходите в розыске по людным местам** — полиция и NPC-стражи реагируют.
5. **Спрячьте улику**, если у вас розыск — это сразу минус 2 звезды.
6. **Документы выдаёт администрация** — паспорт нужно забрать первым.
7. **Бета 51.3 / 51.4 = та же версия, что и 56.1.0-alfa, только черновик.** Ставить смысла нет нигде — ни на сервере, ни в одиночной игре. См. [VERSION-GUIDE.md](../VERSION-GUIDE.md).
8. **Версию мода у всех игроков должна совпадать** — иначе не подключаются пакеты.

## 19. Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| Команды не работают, всё заблокировано | Не введён пароль. Откройте чат (`T`) и введите его |
| Мод не грузится | Проверьте версию Fabric Loader, Fabric API и Java 21 |
| Нет звуков / анимаций | Not Enough Animations вшит в мод, но нужен Fabric API |
| NPC не появляются | Нужен креативный режим и яйцо NPC из таба RPGA |
| Пропали все документы | Восстановите `config/rpga_players.json` из бэкапа |
| Машина не открывается | Подойди ближе и нажми `H` |
| Оружие не стреляет | Нет патронов нужного типа — проверьте описание предмета |
| Бета-функции не работают | Установлена не та версия. Актуальная — **56.1.0-alfa**, беты 51.3 / 51.4 пустые |
| Краш при переводе денег | Известный баг во всех версиях, включая 56.1.0-alfa — см. [KNOWN-ISSUES.md](KNOWN-ISSUES.md#2-критично-проверить-перед-релизом) |

Полный список проблем и ограничений — в **[KNOWN-ISSUES.md](KNOWN-ISSUES.md)**.
